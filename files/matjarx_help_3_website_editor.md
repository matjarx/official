## Getting Started With the Editor

### Accessing Your Website Editor

**Login to your dashboard:**
1. Go to matjarx.com
2. Click "Login"
3. Enter your email and password
4. Click "Edit Website"

**The editor opens in a new window**

## Editing Content

### Changing Text

**To edit text on your site:**

1. Click the text element
2. Type your new content
3. Format as needed (bold, italic, etc.)
4. Click outside to finish
5. Changes save automatically

### Editing Images

**To replace an image:**

1. Click the image
2. Click "Change Image"
3. Upload from your computer
4. Click "Select"
5. Image updates immediately

**To resize an image:**
1. Click the image
2. Drag corner handles to resize
3. Keep aspect ratio to avoid distortion

### Adding New Content

**To add text:**
1. Click "Add Element"
2. Choose "Text"
3. Type your content
4. Style as needed

**To add images:**
1. Click "Add Element"
2. Choose "Image"
3. Upload from computer
4. Position and resize

**To add buttons:**
1. Click "Add Element"
2. Choose "Button"
3. Enter button text
4. Set button link/action

## Working With Pages

### Adding a New Page

**To create a new page:**

1. Click "+" next to Pages list
2. Enter page name
3. Choose template or start blank
4. Page is created
5. Edit content as needed

**Good page names:**
- Services
- About Us
- Contact
- Blog
- FAQ
- Testimonials

### Editing Page Settings

**To edit page details:**

1. Right-click page name
2. Click "Settings"
3. Edit page title
4. Edit page URL (slug)
5. Set SEO details
6. Save

### Organizing Pages

**To reorder pages:**
- Drag page name in sidebar
- Drop in new position
- Order updates immediately

**This affects navigation order**

### Hiding/Deleting Pages

**To hide a page:**
1. Right-click page
2. Click "Hide from Navigation"
3. Page is hidden from menu (but still accessible)

**To delete a page:**
1. Right-click page
2. Click "Delete"
3. Confirm deletion
4. Page is permanently removed

**Caution:** Deleting is permanent. Pages are not recoverable.

## Design & Customization

### Changing Colors

**To change site colors:**

1. Go to "Settings" → "Design"
2. Click "Colors"
3. Choose primary color
4. Choose accent color
5. All pages update automatically

### Changing Fonts

**To change typography:**

1. Go to "Settings" → "Design"
2. Click "Fonts"
3. Choose header font
4. Choose body font
5. Preview updates

### Using Themes

**To change theme:**

1. Go to "Settings" → "Theme"
2. Browse available themes
3. Click "Preview"
4. Click "Apply" to use
5. Your site updates immediately

**All your content transfers** to the new theme

### Custom Design

**For advanced customization:**
- Boost Plan: Limited custom options
- Growth Plan: More customization
- Platinum/Custom: Full customization

Contact support for advanced design changes.

## SEO & Content Optimization

### Setting Page SEO

**To optimize for search engines:**

1. Edit a page
2. Click "SEO Settings"
3. Enter meta title (60 chars)
4. Enter meta description (155 chars)
5. Add keywords (optional)
6. Save

### Optimizing Content

**Best practices:**
- Use keywords naturally in content
- Write clear, descriptive headings
- Include images with alt text
- Link to related pages
- Write substantial content (300+ words)

### Adding Meta Information

**Meta Title:** What appears in Google search results  
**Meta Description:** Preview text under title in results

## Troubleshooting

### Changes Not Saving

**If changes don't save:**

1. Check internet connection
2. Refresh page
3. Try saving again
4. Contact support if issue persists

### Images Not Loading

**If images don't display:**

1. Check file size (< 5MB)
2. Try different format (JPG vs PNG)
3. Re-upload image
4. Clear browser cache

### Layout Issues

**If design looks broken:**

1. Refresh the page
2. Try different browser
3. Clear browser cache
4. Contact support

## Keyboard Shortcuts

### Quick Editing Tips

**Ctrl/Cmd + Z:** Undo last change  
**Ctrl/Cmd + S:** Save changes  
**Ctrl/Cmd + A:** Select all
