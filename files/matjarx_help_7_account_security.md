## Two-Factor Authentication (2FA)

### What is Two-Factor Authentication?

2FA adds extra security by requiring two things to login:
1. Your password
2. A code from your phone

**Benefits:**
- Extra security
- Protects against hacking
- Especially important if password leaked
- Recommended for all users

### Setting Up 2FA

**Prerequisites:**
- Smartphone (iPhone or Android)
- Authenticator app (Google Authenticator, Microsoft Authenticator, Authy)

**Setup steps:**

1. Go to "Account Settings"
2. Click "Security" or "Two-Factor Auth"
3. Click "Enable 2FA"
4. Download authenticator app (if not already)
5. Scan QR code with app
6. Enter 6-digit code from app
7. Save backup codes (in safe place!)
8. Confirm setup

### Using 2FA to Login

**When logging in:**
1. Enter email and password (as normal)
2. You'll be asked for 2FA code
3. Open authenticator app
4. Enter 6-digit code shown
5. Click "Verify"
6. Access granted

**Codes change:** New code every 30 seconds

### Backup Codes

**If you lose phone:**

Backup codes let you login without app.

**Keep them safe:**
- Write down and store securely
- Save in password manager
- Don't share with anyone
- Don't lose them

**If needed:**
1. Enter email and password
2. Click "Use backup code"
3. Enter one backup code
4. Access granted
5. That backup code can't be reused

### Disabling 2FA

**If you want to disable:**
1. Go to "Account Settings"
2. Click "Security"
3. Click "Disable 2FA"
4. Confirm (you'll lose extra security)

**Not recommended** unless necessary

## Security Best Practices

### Protecting Your Account

**Do:**
- ✅ Use strong, unique password
- ✅ Enable two-factor authentication
- ✅ Change password every 3-6 months
- ✅ Never share password
- ✅ Log out of public computers
- ✅ Use password manager
- ✅ Keep email updated
- ✅ Review login activity

**Don't:**
- ❌ Share password with anyone
- ❌ Use same password for multiple sites
- ❌ Write password on paper
- ❌ Give password to support (they never need it)
- ❌ Use easy-to-guess passwords (birthdate, name)
- ❌ Login on public Wi-Fi without VPN

### Suspicious Activity

**If you notice:**
- Unexpected login notifications
- Password changed but you didn't
- Account modifications you didn't make
- Unusual activity

**Take action immediately:**
1. Change password
2. Check email (change if hacked)
3. Enable 2FA
4. Review connected apps
5. Contact support

### Password Managers

**Recommended:** Use password manager

**Benefits:**
- Remember all passwords
- Generate strong passwords
- Secure storage
- Sync across devices

**Popular options:**
- LastPass
- 1Password
- Dashlane
- Bitwarden (free)

## Account Recovery

### If Your Account is Compromised

**If you suspect hacking:**

**Immediately:**
1. Change password from secure computer
2. Enable 2FA
3. Review account settings
4. Check connected apps
5. Review recent activity

**Then:**
1. Contact MatjarX support
2. Provide details about suspicious activity
3. We'll investigate and help secure account

### Recovery Process

**If locked out:**

1. Try password reset
2. Check email for reset link
3. If email hacked: Contact support with proof of identity
4. Verify ownership (we'll help)
5. Regain access to account

## FAQ

**Q: How often should I change my password?**  
A: Every 3-6 months is recommended. Immediately if compromised.

**Q: Is 2FA required?**  
A: No, but highly recommended for security.

**Q: What if I lose my phone?**  
A: Use backup codes to login. Disable 2FA and re-enable with new device.

**Q: Can I have multiple accounts?**  
A: Yes. Manage separately or contact support to link.

**Q: What if I forget my 2FA backup codes?**  
A: Contact support with proof of identity. We can help restore access.

**Q: Can you reset my password?**  
A: You can reset yourself via email. If email hacked, contact support with ID proof.

**Q: Is my data backed up?**  
A: Yes! Daily backups. Can be restored if needed.
