## FAQ

**Q: How do I protect client privacy?**  
A: Use client permission, blur faces if needed, focus on decor/design.

**Q: Should I show prices?**  
A: Yes! Transparency helps. Packages + price ranges reduce unqualified inquiries.

**Q: How many events should I showcase?**  
A: Start with 20-30 diverse events. Update quarterly with new work.

**Q: Will this really get me more bookings?**  
A: Yes! Portfolio websites book 250%+ more events than those without.

**Q: Can I showcase vendor partnerships?**  
A: Absolutely! It builds credibility and strengthens vendor relationships.
